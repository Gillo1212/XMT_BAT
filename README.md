# XMT BAT — Site web et back-office de gestion immobilière et de services

Application web réalisée pour **XMT BAT**, entreprise de bâtiment, d'immobilier et de services basée à Rufisque (Sénégal). Elle réunit le site vitrine de l'entreprise et un back-office pour gérer son activité.

> 🇬🇧 *Company website and management back-office for a construction, real estate and services company in Senegal (React, TypeScript, Tailwind CSS).*

## Fonctionnalités

**Site vitrine**
- Accueil, présentation de l'entreprise, actualités et blog
- Catalogue des biens immobiliers
- Demande de devis en ligne

**Back-office**
- Tableau de bord de l'activité
- Biens, propriétaires, locations et visites
- Demandes, devis et interventions
- Paiements et suivi financier
- Personnel, équipes de ménage et documents
- Connexion sécurisée à l'espace de gestion

> ℹ️ Cette version front-end fonctionne avec des **données de démonstration** (dossier `src/mocks`), en attendant le branchement à une API.

## Stack technique

React 19 · TypeScript · Vite · Tailwind CSS · React Router · i18next · Lucide

## Démarrage

```bash
npm install
npm run dev
```
